# پیگیری هوشمند پرونده‌های حقوقی

> سامانه‌ای برای مدیریت و پیگیری پرونده‌های حقوقی از طریق پیام‌رسان **بله**، همراه با دانشنامه حقوقی و فرمت استاندارد ذخیره‌سازی اطلاعات پرونده.

---

## 🎯 چرا این پروژه ساخته شد؟

پیگیری پرونده‌های حقوقی — به‌ویژه برای دفاتر خدمات قضایی و وکلا — فرآیندی پرجزئیات و زمان‌بر است:

- **مراحل متعدد:** ثبت دادخواست، ابلاغ، جلسات، کارشناسی، صدور رأی و اجرا هر کدام مهلت‌ها و اقدامات خاص خود را دارند
- **پراکندگی اطلاعات:** اطلاعات هر پرونده در فایل‌ها، یادداشت‌ها و حافظه وکیل پراکنده است
- **خطای انسانی:** فراموشی مهلت‌ها، جا‌افتادن مدارک و از دست رفتن پیگیری‌ها
- **عدم دسترسی سریع:** نیاز به دسترسی فوری به وضعیت پرونده در هر زمان و مکان

این پروژه با ترکیب **بازوی پیام‌رسان بله** + **فایل‌های مارک‌داون ساختاریافته** + **دانشنامه حقوقی**، این مشکلات را حل می‌کند:

- ✅ دسترسی به وضعیت پرونده با چند دستور ساده در تلفن همراه
- ✅ فرمت یکسان و استاندارد برای ذخیره‌سازی اطلاعات هر پرونده
- ✅ یادآوری خودکار مهلت‌ها و اقدامات مهم
- ✅ حریم خصوصی کامل — داده‌های پرونده هرگز از کامپیوتر شما خارج نمی‌شود

## 🚀 شروع سریع

### ۱. کلون کردن مخزن

```bash
git clone <آدرس-مخزن>
cd legal_case
```

### ۲. راه‌اندازی بازو

```bash
cd bot
pip install -r requirements.txt
cp .env.example .env   # توکن بازو را وارد کنید
python bot.py
```

> راهنمای کامل راه‌اندازی: [bot/README.md](./bot/README.md)

### ۳. ایجاد پرونده جدید

ساختار فایل‌های پرونده و فرمت‌های مورد انتظار بازو را در [cases/README.md](./cases/README.md) ببینید. پوشه پرونده جدید را در `cases/` بسازید و فایل‌ها را با فرمت مستندشده بنویسید.

## 🔒 حریم خصوصی و امنیت

> **این پروژه بر اساس اصل «داده‌ها هرگز از دستگاه شما خارج نمی‌شوند» طراحی شده است.**

| اصل | توضیح |
|:---|:---|
| 🚫 داده پرونده در گیت نیست | فایل‌های `cases/` در `.gitignore` هستند و هرگز کامیت نمی‌شوند |
| 🔑 توکن در کد نیست | توکن بازو فقط از متغیر محیطی یا فایل `.env` (gitignored) خوانده می‌شود |
| 🏠 پردازش لوکال | بازو اطلاعات را مستقیماً از فایل‌های لوکال شما می‌خواند |
| 📡 بدون سرور مرکزی | هیچ داده‌ای به سرور ثالث ارسال نمی‌شود |

**نکته:** ریپوی عمومی فقط شامل کد بازو، مستندات و دانشنامه حقوقی است — نه هیچ داده شخصی یا پرونده‌ای.
