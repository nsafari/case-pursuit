# بازوی پیگیری کیس‌های حقوقی 🏛️

بازویی برای پیگیری آخرین وضعیت کیس‌های حقوقی از طریق پیام‌رسان بله

## ویژگی‌ها ✨

- 📋 نمایش آخرین وضعیت پرونده
- 📄 جزئیات کامل پرونده
- ⏰ مهلت‌های مهم و نزدیک
- 📑 لیست مدارک مورد نیاز
- 📞 اطلاعات تماس شعبه
- 🔄 به‌روزرسانی خودکار از فایل‌های پروژه
- 📁 پشتیبانی از چندین پرونده
- 🔘 دکمه‌های شیشه‌ای برای انتخاب آسان پرونده
- 🔍 جستجو در پرونده‌ها

## پیش‌نیازها 📦

- پایتون ۳.۷ یا بالاتر
- پکیج‌های پایتون (در فایل `requirements.txt`)
- توکن بازو از پیام‌رسان بله

## راه‌اندازی 🚀

### ۱. دریافت توکن بازو

۱. اپلیکیشن بله را باز کنید
۲. به جستجوی `@BotFather` بروید
۳. دستور `/newbot` را ارسال کنید
۴. نام و نام کاربری بازو را انتخاب کنید
۵. توکن دریافتی را ذخیره کنید

### ۲. نصب وابستگی‌ها

```bash
cd bot
pip install -r requirements.txt
```

### ۳. تنظیم توکن

روش ۱: متغیر محیطی (توصیه شده)
```bash
export BALE_BOT_TOKEN="YOUR_TOKEN_HERE"
```

روش ۲: ویرایش فایل config.py
```python
BOT_TOKEN = "YOUR_TOKEN_HERE"
```

### ۴. اجرای بازو

```bash
python bot.py
```

## دستورات بازو 📱

| دستور | توضیح |
|-------|-------|
| `/start` | خوشامدگویی و نمایش منوی اصلی |
| `/help` | راهنمای دستورات |
| `/cases` | لیست تمام پرونده‌ها با دکمه‌های انتخاب |
| `/select [نام]` | انتخاب پرونده فعال |
| `/status` | آخرین وضعیت پرونده انتخاب شده |
| `/case` | جزئیات کامل پرونده |
| `/deadline` | مهلت‌های مهم |
| `/documents` | لیست مدارک |
| `/contact` | اطلاعات تماس شعبه |
| `/search [عبارت]` | جستجو در پرونده‌ها |

### استفاده از دکمه‌های شیشه‌ای

با ارسال دستور `/cases`، لیست پرونده‌ها به همراه دکمه‌های شیشه‌ای نمایش داده می‌شود. کافی است روی دکمه پرونده مورد نظر کلیک کنید تا به صورت خودکار انتخاب شود.

## ساختار فایل‌ها 📁

```
bot/
├── bot.py              # فایل اصلی بازو
├── config.py           # پیکربندی
├── case_manager.py     # مدیریت پرونده‌ها
├── requirements.txt    # وابستگی‌ها
└── README.md           # این فایل
```

## نحوه عملکرد ⚙️

بازو اطلاعات خود را مستقیماً از فایل‌های موجود در پوشه `cases/` می‌خواند. با هر بار اجرای دستور، فایل‌ها مجدداً خوانده شده و اطلاعات به‌روزرسانی می‌شود.

### فایل‌های خوانده شده:

- `00-overview.md` - خلاصه و وضعیت پرونده
- `01-timeline.md` - زمان‌بندی و مهلت‌ها
- `04-documents.md` - لیست مدارک
- `06-correspondence.md` - اطلاعات تماس

## نکات امنیتی 🔒

- ⚠️ از متغیرهای محیطی برای ذخیره توکن استفاده کنید
- ⚠️ فایل `.gitignore` را بررسی کنید تا توکن ردیابی نشود

## عیب‌یابی 🐛

### خطا: توکن نامعتبر
- مطمئن شوید توکن صحیح را از @BotFather دریافت کرده‌اید
- توکن را در config.py یا متغیر محیطی تنظیم کنید

### خطا: فایل‌ها یافت نشد
- مطمئن شوید پوشه `cases/` در مسیر درست قرار دارد
- فایل‌های مورد نیاز (00-overview.md و ...) باید موجود باشند

### بازو پاسخ نمی‌دهد
- اتصال اینترنت را بررسی کنید
- لاگ‌ها را بررسی کنید
- بازو را مجدداً راه‌اندازی کنید

## توسعه 🔧

برای اضافه کردن قابلیت‌های جدید:

1. دستور جدید را در `bot.py` اضافه کنید
2. تابع مربوطه را در `case_manager.py` پیاده‌سازی کنید
3. پیام پاسخ را در `config.py` تعریف کنید
