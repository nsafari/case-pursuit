## 🔍 ساختار فایل‌ها و فرمت‌های مورد انتظار bot

### ۱. `00-overview.md` — خلاصه کیس (الزامی)

bot از این فایل برای دستورات `/status`، `/case`، `/contact` و `/cases` استفاده می‌کند.

**جدول اطلاعات کلی (فرمت ستون‌ها باید دقیقاً مطابق زیر باشد):**

```markdown
| ردیف | شرح | مقدار |
|:---:|:---|:---|
| ۱ | عنوان کیس | عنوان کیس را اینجا بنویسید |
| ۲ | شماره پرونده | شماره پرونده |
| ۳ | مرجع صالح | نام شعبه دادگاه |
| ۴ | تاریخ شروع | ۱۴۰۵/۰۶/۰۰ |
| ۵ | آخرین به‌روزرسانی | ۳۰ سپتامبر ۲۰۲۶ |
```

**فیلدهای استخراج‌شده توسط bot:**

| عنوان ستون | استفاده در دستور | توضیح |
|:---|:---:|:---|
| `عنوان کیس` | `/status` `/case` `/cases` | عنوان اصلی پرونده |
| `شماره پرونده` | `/status` `/case` `/cases` | شماره پیگیری پرونده |
| `مرجع صالح` | `/case` `/contact` | نام شعبه و دادگاه |
| `تاریخ شروع` | `/case` | تاریخ شروع رسیدگی |
| `آخرین به‌روزرسانی` | `/status` | تاریخ آخرین ویرایش |

**بخش‌های متنی:**

```markdown
## وضعیت فعلی

### مرحله کنونی
**در انتظار رسیدگی**    ← استخراج‌شده توسط /status

---

## وضعیت پرونده

- در انتظار ثبت دادخواست   ← استخراج‌شده برای payment_status
```

**ساختار کامل طرفین (برای `/case`):**

```markdown
## طرفین

### خواهان
- **نام:** نام خواهان
- **سمت:** خواهان

### خوانده
- **نام:** نام خوانده
- **سمت:** خوانده
```

> **نکته:** فرمت فیلدها باید دقیقاً `- **نام:**` و `- **سمت:**` باشد.

### ۲. `01-timeline.md` — زمان‌بندی و مهلت‌ها (الزامی)

bot از این فایل برای دستور `/deadline` استفاده می‌کند.

**بخش‌های مورد نیاز:**

```markdown
## تاریخ‌های مهم گذشته

- [x] تاریخ ثبت دادخواست - ۱۴۰۵/۰۶/۱۵ - دادخواست به دادگاه ارسال شد
- [x] ارسال مدارک - ۱۴۰۵/۰۶/۲۰ - کپی مدارک تحویل دادگاه
- [x] پرداخت هزینه دادرسی - ۱۴۰۵/۰۶/۲۵ - رسید پرداخت دریافت شد

---

## تاریخ‌های مهم آینده

- [ ] ابلاغ به خوانده - ۱۴۰۵/۰۷/۱۰ - ارسال ابلاغیه رسمی
- [ ] جلسه رسیدگی - ۱۴۰۵/۰۷/۲۵ - حضور در دادگاه
- [ ] صدور حکم - ............
```

**نکته مهم فرمت:**
- فرمت هر آیتم: `- [x] رویداد - تاریخ - توضیح`
- آیتم‌های انجام‌شده: `- [x]`
- آیتم‌های آینده: `- [ ]`
- هر آیتم باید در یک خط جداگانه باشد

### ۳. `04-documents.md` — لیست مدارک (الزامی)

bot از این فایل برای دستور `/documents` استفاده می‌کند.

**ساختار چک‌لیست:**

```markdown
### مدارک تکمیل شده

- [x] قرارداد اصلی

- [x] کارت ملی خوانده
- [x] رسید پرداخت هزینه دادرسی

---

### مدارک در حال تهیه

- [ ] استعلام ثبتی
- [ ] استعلام شهرداری

```

**نکته مهم فرمت:**
- عنوان بخش‌ها باید با `###` باشد: `### مدارک تکمیل شده` و `### مدارک در حال تهیه`
- مدارک تکمیل‌شده: `- [x]`
- مدارک در انتظار: `- [ ]`
- هر مدرک باید در یک خط جداگانه باشد

### ۵. `07-expert-scenarios.md` — سناریوهای کارشناسی (پیشنهادی)

bot از این فایل برای دستور `/scenarios` استفاده می‌کند.

**ساختار هر سناریو:**

```markdown
**موضوع:** عنوان سناریو

## سناریوی اول: عنوان سناریو

### نحوه معرفی به کارشناس
> متن پیشنهادی ارائه به کارشناس...

### مستندات مورد نیاز
- سند ۱
- سند ۲
- سند ۳

### نکته مهم
توضیحات مهم درباره این سناریو...
```

**نکته مهم فرمت:**
- خط `**موضوع:** عنوان سناریو` باید نزدیک به بالای فایل قرار بگیرد
- عنوان سناریو باید با `## سناریوی` شروع شود
- زیربخش‌ها با `###` مشخص شوند
- فیلدهای استخراج‌شده: `موضوع`، `نحوه معرفی`، `مستندات`، `نکته مهم`، `توضیح`، `پاسخ ما`، `احتمال وقوع`

## 📌 نکات مهم برای رعایت فرمت

### ۱. جدول‌ها
- عنوان ستون‌ها باید **دقیقاً** مطابق فهرست بالا باشند
- مثال: `عنوان کیس` نه `عنوان پرونده`
- مثال: `شماره پرونده` نه `شماره`

### ۲. چک‌لیست‌ها
- از فرمت GitHub Markdown استفاده کنید: `- [x]` و `- [ ]`
- هر آیتم در یک خط جداگانه

### ۳. عنوان‌های بخش
- برای استخراج مهلت‌ها: `## تاریخ‌های مهم گذشته` و `## تاریخ‌های مهم آینده`
- برای وضعیت: `## وضعیت فعلی` و `## وضعیت پرونده`
- برای سناریوها: `## سناریوی اول: ...`

### ۴. تاریخ‌ها
- از فرمت شمسی استفاده کنید: `۱۴۰۵/۰۶/۱۵`
- یا فرمت میلادی: `30 سپتامبر ۲۰۲۶`

## 🔗 ارتباط با bot

### نگاشت دستورهای bot به فایل‌ها و بخش‌ها

| دستور | فایل | بخش استخراج‌شده | اطلاعات استخراج‌شده |
|:---|:---|:---|:---|
| `/cases` | `00-overview.md` | جدول `## اطلاعات کلی` | نام، شماره، عنوان |
| `/status` | `00-overview.md` | جدول `## اطلاعات کلی` + `### مرحله کنونی` | شماره، موضوع، وضعیت، به‌روزرسانی |
| `/case` | `00-overview.md` | `## طرفین`، `## موضوع و خواسته`، جدول اطلاعات | جزئیات کامل، طرفین، مرجع |
| `/deadline` | `01-timeline.md` | `## تاریخ‌های مهم گذشته`، `## تاریخ‌های مهم آینده` | مهلت‌های گذشته و آینده |
| `/documents` | `04-documents.md` | `### مدارک تکمیل شده`، `### مدارک در حال تهیه` | مدارک تکمیل‌شده و در انتظار |
| `/contact` | `06-correspondence.md` | `## اطلاعات تماس شعبه` | اطلاعات تماس شعبه |
| `/scenarios` | `07-expert-scenarios.md` | `**موضوع:**`، `## سناریوی ...` | سناریوهای کارشناسی |
| `/search` | `00-overview.md` | کل فایل | جستجو در عنوان و محتوا |
