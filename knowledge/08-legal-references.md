# فهرست مواد قانونی مرتبط

## قانون مدنی ایران

### بخش اول: قواعد عمومی قراردادها

#### مواد مربوط به صحت معاملات
| ماده | موضوع |
|:---:|:---|
| ۱۰ | قراردادهای خصوصی نسبت به کسانی که آن را منعقد نموده‌اند نافذ است |
| ۱۸۳ | تعریف عقد |
| ۱۹۰ | شرایط اساسی صحت معامله (قصد، اهلیت، موضوع معین، مشروعیت جهت) |
| ۱۹۱ | عقد محقق می‌شود به قصد انشا |
| ۲۱۰ | متعاملین باید برای معامله اهلیت داشته باشند |
| ۲۱۱ | برای اهل بودن باید بالغ و عاقل و رشید باشد |
| ۲۱۲ | معامله صغیر غیرممیز و مجنون باطل است |
| ۲۱۴ | مورد معامله باید مال یا عملی باشد |
| ۲۱۵ | مورد معامله باید مالیت داشته باشد |
| ۲۱۶ | مورد معامله باید مبهم نباشد |

| ۲۲۱ | مسئولیت خسارت ناشی از تخلف از تعهد |
| ۲۲۳ | اصل صحت در معاملات |

### بخش دوم: خیارات

| ماده | خیار | توضیح |
|:---:|:---|:---|
| ۳۹۶ | انواع خیارات | فهرست خیارات |

| ۳۹۸ | خیار حیوان | فقط معامله حیوان |
| ۳۹۹ | خیار شرط | در صورت شرط در عقد |
| ۴۰۱ | بطلان شرط فاقد مدت | در صورت عدم تعیین مدت |
| ۴۰۲ | خیار تأخیر ثمن | ۱۰ روز |
| ۴۱۰ | خیار رویت و تخلف وصف | در صورت تخلف اوصاف |
| ۴۱۶ | خیار غبن | مغبون شدن فاحش |
| ۴۱۷ | تعریف غبن فاحش | عرفی و غیرقابل مسامحه |
| ۴۱۸ | سقوط خیار غبن | در صورت جبران تفاوت |
| ۴۱۹ | فوری بودن خیار غبن | پس از علم |
| ۴۲۲ | خیار عیب | وجود عیب در مورد معامله |
| ۴۲۳ | فوری بودن خیار عیب | پس از علم |
| ۴۳۸ | خیار تدلیس | عملیات فریبکارانه |
| ۴۳۹ | تدلیس دوطرفه | هم بایع و هم مشتری |
| ۴۴۰ | فوری بودن خیار تدلیس | پس از علم |
| ۴۴۱ | خیار تبعض صفقه | باطل بودن قسمتی از معامله |
| ۴۴۸ | خیار تخلف شرط | عدم اجرای شروط |
| ۴۴۸ | اسقاط خیارات | امکان اسقاط در ضمن عقد |
